1. To read EIP you can do:
   ```asm
   call test;
   test: pop eax;  
   ```
   The ```mov``` instruction does not support EIP

2. JMP version:
   ```asm
   mov eax,0xAABBCCDD;
   jmp eax;
   ```
   RET version:
   ```asm
   push 0xAABBCCDD;
   ret;
   ```

3. If the stack pointer was not properly restored, the function would return to one of its arguments, enabling arbitrary jumps.

4. Expectation, as with ```mul``` instructions, a too large return type might be stored in a combination of registers (EDX:EAX), another option is returning an address to memory in eax and reading it.
   
   gcc - EDX:EAX
   
   clang - seems to use the address to memory version
